# Exploratory Data Analysis of FIFA World Cup Players and Performance

## Project Overview
This project performs Exploratory Data Analysis (EDA) on FIFA World Cup player and performance data.

## Objectives
- Analyze player statistics
- Explore player performance
- Identify trends and patterns
- Visualize important insights
- Compare player and team performance

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Project Notebook
The complete analysis is available in the Jupyter Notebook:

`FIFA_World_Cup_EDA.ipynb`
